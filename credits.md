# Credits and inspirations

Weave is an independent project informed by the following open-source projects and ideas.

- **[beets](https://github.com/beetbox/beets)** ([website](https://beets.io/)): library organization, metadata enrichment, music identification, flexible attributes, CLI workflows, and smart playlist concepts.
- **[Hummingbird](https://git.mailliw.org/hummingbird/hummingbird)**: native Rust/GPUI music-player design, local playback, queue management, and lyrics UI.
- **[Tagify](https://tagify.fm/)**: user-defined tags, combinable filters, dynamically populated smart playlists, and optional tag sharing.
